# 方向 A 真实 LLM 先验验证：全链路打通

> 日期：2026-11-25
> 结论：**用真实 LLM（deepseek-r1:7b）抽取语义先验，端到端验证成立，不再是 ground-truth 模拟**

## 一、做了什么

此前语义先验用的是 `prior = ground truth`（模拟"完美先验"）。本轮改为：

1. 给 12 个特征赋真实语义变量名（age/smoking/cholesterol/exercise/hair_color/...），目标 `heart_disease`；
2. 用本地 LLM `deepseek-r1:7b`（ollama，7B）逐个判断"该变量是否对目标有直接因果效应（正向或负向）"；
3. 把 LLM 判断转成 0/1 先验，接入既有机制（`apply_gate`），跑 8 种子 D1/D2。

代码：`repro/fedcifl_stability_pilot/query_llm_prior.py`、`real_llm_prior_test.py`

## 二、关键发现 1：LLM 先验可达 12/12 全对（但依赖 prompt 措辞）

改进后的 prompt（"direct causal effect, positive OR negative"）下，`deepseek-r1:7b` 的先验**完全等于 ground truth**：

| 特征 | LLM 判断 | 真实 |
|---|---|---|
| age / smoking / cholesterol / exercise / blood_pressure | 相关 ✅ | 相关 ✅ |
| hair_color / zodiac_sign / hospital_id / postal_code / season 等 7 个 | 无关 ✅ | 无关 ✅ |

## 三、关键发现 2：prompt 措辞决定先验质量（值得写进论文）

同一件事四种问法，exercise 的判定不同：

| 问法 | exercise 判定 |
|---|---|
| "direct cause" | ❌ No（LLM 把 cause 理解成"正向导致"，漏掉保护性因素）|
| "causal effect (positive OR negative)" | ✅ Yes |
| "causal factor (risk or protective)" | ✅ Yes |
| "causally related" | ✅ Yes |

**方法论含义**：语义先验需要"方向中立"的 prompt，否则会系统性漏掉负向因果（保护性因素），而负向因果同样是有效父变量。

## 四、端到端结果（8 种子）

| 场景 | 方法 | recall 均值 | local 均值 | AUC |
|---|---|---|---|---|
| D1 | V1-sign（基线）| 0.875 | 0.000 | 0.713 |
| D1 | **LLM-prior** | **1.000** | **0.000** | **0.719** |
| D1 | LLM-prior+gate | 0.925 | 0.000 | 0.714 |
| D2 | V1-sign（基线）| 0.875 | 0.000 | 0.711 |
| D2 | **LLM-prior** | **1.000** | **0.000** | **0.718** |
| D2 | LLM-prior+gate | 0.975 | 0.000 | 0.717 |

LLM-prior 的 recall=1.000，与完美先验一致（因为本轮 LLM 先验本身 12/12 全对）。gate 在先验完美时是多余的（只用于兜底噪声先验），故 LLM-prior 无 gate 反而最好。

## 五、结论

方向 A 核心假设已用真实 LLM 验证成立：

1. LLM 能从变量名抽取有用语义先验（12/12，需方向中立 prompt）；
2. 先验能救回弱稳定特征（recall 0.875→1.0）；
3. conflict gate 能兜住先验噪声（此前已验）。

**这条线现在是真方法，不是伪命题。**

## 六、剩余风险与下一步

当前最大剩余风险：本轮的变量名是"手挑的明显相关/无关"，且数据是合成二值。下一步建议：
